shapeforge

3D modeling for AI agents. Describe a model, and your agent builds it, looks at it, fixes it, and hands you an OBJ file.

GitHub · npm · Download · MIT license

What it is

shapeforge is an MCP server: a tool your AI agent can call. It gives the agent a small modeling toolkit designed around how language models work. The agent describes named parts with real dimensions, sees the result rendered from several angles, measures it, corrects mistakes, and exports a standard OBJ file.

It works with Claude Code, Claude Desktop, GitHub Copilot (VS Code and CLI), Cursor, OpenAI Codex, OpenCode, Windsurf, and any other agent that supports MCP. It's a single native program for macOS, Windows and Linux with nothing else to install.

Install

With Node.js installed, one command sets it up for your agent:

npx -y shapeforge install claude-code

Replace claude-code with claude-desktop, cursor, windsurf, vscode, copilot-cli, opencode, codex, or all. Then restart the agent.

Without Node.js, download the program for your system from the latest release and run shapeforge install <agent>. Claude Desktop users can download shapeforge.mcpb instead and double-click it.

Try it

Ask your agent the way you would brief a designer:

Model a wooden dining chair, about 45 cm seat height, with a slightly reclined back. Export it as OBJ.
Make a coffee mug with a handle and a saucer. Show me the front and top views before exporting.

Models are saved in Documents/shapeforge in your home folder (~/shapeforge on Linux).

How it works

  1. Describe. The agent plans the model as named parts: boxes, cylinders, lathe profiles, extrusions, and boolean combinations of them.
  2. Build. shapeforge turns each description into a clean triangle mesh.
  3. See. The agent receives one image with front, side, top and perspective views, labeled with axes and a measuring grid.
  4. Measure. Exact sizes, gaps and contacts catch what pictures miss, for example a backrest floating 1.2 mm above its seat.
  5. Fix and export. Placement tools put parts exactly where they belong. The result is written as OBJ and MTL, one named part per object.

Tools

ToolPurpose
add_objectsCreate parts: box, sphere, cylinder, cone, capsule, torus, plane, extrusion, lathe, mesh, boolean (CSG), group
update_objects, delete_objects, undoEdit, remove, step back
place_on, align_objects, mirror_object, array_objectExact placement, symmetry and repetition
renderImages from any angle, with labels, highlighting and zoom
inspectSizes, positions, volume, contacts and warnings
export_obj, save_scene, load_sceneOBJ export and editable scene files

Source

shapeforge is written in C++20 with no third-party dependencies. It renders with Vulkan and falls back to a built-in CPU renderer. The code, documentation and issue tracker are on GitHub.
