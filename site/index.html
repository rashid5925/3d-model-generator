How it works

It doesn't just generate. It checks its own work.

Models make mistakes in 3D. shapeforge lets them catch those mistakes the way a designer would: by looking at the model and measuring it.

Model a small dining table with a chair, a mug and a bowl on it.
◆add_objects · table, 4 legs, chair, mug, bowl…
◆render · front, right, top, iso
!inspect backrest floats 1.2 mm above the seat
◆update_objects · backrest y 0.670 → 0.665
✓inspect no floating parts
✓export_obj → table_set.obj · 14 parts · 11k triangles

What the agent sees: four labeled views with axes and a measuring grid, all in one image.

Describe

The agent plans named parts with real sizes, like seat, legs and backrest.

Build

Primitives, extrusions, lathes and CSG booleans become clean meshes. add_objects

See & measure

Multi-view renders plus exact numbers expose gaps, overlaps and wrong sizes. render inspect

Export

OBJ + MTL with every part named and colored, ready for Blender, Unity or a slicer. export_obj

Features

A modeling toolkit designed for AI

Not a human tool with an API bolted on. Every tool is shaped around how language models think and where they struggle.

Describe, don't draw

Parts are short JSON descriptions with real dimensions. No vertices, no scripting, and no API to memorize.

Sees its own work

Front, side, top and 3D views in one image, labeled with axes and grid spacing so the model can reason about direction.

Measures exactly

Sizes, gaps, contacts and warnings like "floats 1.2 mm above the seat", because pictures alone don't fix dimensions.

Places things precisely

Rest a part on a surface, mirror left to right, repeat in rows or rings, align edges. The 3D math is done for the model.

Real CAD-style booleans

Union, subtract and intersect with smooth blending for holes, handles and organic joins, simplified into clean, light meshes.

One native binary

Fast C++ with GPU rendering through Vulkan and an automatic CPU fallback. It runs locally on macOS, Windows and Linux.
